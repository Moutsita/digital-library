📚 Bibliothèque Numérique

Plateforme académique de gestion de bibliothèque avec système de recommandation basé sur l'historique des emprunts.

🔗 Accès aux microservices

📚 Books Service
Gestion des livres 👤 Users Service
Gestion des utilisateurs 📦 Loans Service
Gestion des emprunts 🤖 Recommendation Service
API de recommandations

🎯 Fonctionnalités du projet

  • Ajout, modification, suppression et recherche de livres
  • Gestion des utilisateurs (Étudiants, Professeurs, Personnel)
  • Emprunt, retour et historique des livres
  • Détection des retards
  • Système de recommandation de livres
  • Conteneurisation avec Docker
  • Versioning avancé avec Git
  • Versioning des données et modèles avec DVC

⚙️ Technologies utilisées

FastAPI PostgreSQL Docker Docker Compose Git DVC scikit-learn Nginx
