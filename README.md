# Digital Library

## Commande de récupération du dépôt
```bash
git clone https://github.com/Moutsita/digital-library.git
```

## Lancement

```bash
docker compose up -d --build
```

## URLs

- Frontend : http://localhost:8080
- Books Service : http://localhost:8001/docs
- Users Service : http://localhost:8002/docs
- Loans Service : http://localhost:8003/docs
- Recommendation Service : http://localhost:8004/docs
